# Einführung in die Sprache Dart anhand von Beispielen

> ⚠️ **Dieses Repository ist kein Softwareprojekt.** Es gibt keine Anwendung zu installieren, kein Paket zu veröffentlichen und keine Code-Probleme zu beheben: Es handelt sich um **Kursmaterial**, geschrieben für Studierende, die die Sprache Dart lernen.

## 📖 Den Kurs lesen

Der Kurs kann online unter dieser Adresse gelesen werden:

**👉 [https://stahe.github.io/de-dart-sept-2026/](https://stahe.github.io/de-dart-sept-2026/)**

Zum Lesen ist keine Installation erforderlich: Ein einfacher Browser genügt.

## 🎯 Für wen ist dieser Kurs?

Dieser Kurs richtet sich an Studierende, die **keinerlei Vorkenntnisse** in der Sprache Dart haben.
Er folgt demselben Prinzip wie der Kurs *Einführung in die Sprache TypeScript und das
NestJS-Framework*: Eine Sprache wird anhand einer Reihe kleiner, eigenständiger Skripte gelernt,
die Zeile für Zeile kommentiert sind, statt durch eine theoretische Erklärung ihrer Grammatik. Der Aufbau des Kurses folgt dem des Schritt-für-Schritt-Kurses zu TypeScript, mit einem Dart-Skript neben jedem TypeScript-Skript, um direkt zu vergleichen, wie die beiden Sprachen dieselbe Anforderung lösen.

## 📚 Gliederung des Kurses

Der Kurs ist in große Abschnitte gegliedert:

1. **Einrichtung der Entwicklungsumgebung** — Werkzeuge prüfen, VS-Code-Projekt einrichten, erstes Skript, statische Analyse, Linter und die Dart-Erweiterung.
2. **Grundlagen von Dart** — Grundlagen der Sprache, Arrays, Objekte,
   Zeichenketten, reguläre Ausdrücke, Funktionen, Fehler und
   Ausnahmen, Module, ereignisgesteuerte Programmierung und asynchrone Funktionen,
   Klassen sowie Neuerungen in Dart 3.x (Records, Patterns, Sealed Classes).
3. **Installation eines NestJS-Servers** — der Server zur Einkommensteuerberechnung,
   direkt aus dem TypeScript-Kurs übernommen: Er dient als realistisches Ziel zum Testen der HTTP-Funktionen von Dart,
   so wie er im ursprünglichen Kurs als Ziel für die HTTP-Clients dient. (Die Kapitel, die NestJS selbst vermitteln, wurden hier bewusst weggelassen: Es ist ein
   Thema, das nicht direkt zum Erlernen der Sprache Dart gehört.)
4. **HTTP-Funktionen von Dart und Clients für den Steuerberechnungsdienst** — vier
   Client-Varianten für denselben Server: ein einfaches CLI-Skript, getrennte DAO-/Geschäftslogikschichten,
   ein kompiliertes Projekt und schließlich eine vollständige Webanwendung mit HTML-Oberfläche.
5. **Datenbankzugriff** — der native MySQL-Treiber, gefolgt von einem von Hand geschriebenen „leichtgewichtigen ORM", da es für Dart kein ausgereiftes Pendant zu TypeORM oder Prisma gibt.
